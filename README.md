# Trails SDK

Trails is an API-testing platform for defining, running, and reviewing tests. `io.github.yaforster:trails-sdk` is its
embeddable Spring Boot server and the contract used by independently replaceable adapters. A customer application
combines it with persistence, browser, and printing adapters; authentication and notifications are optional.

Alignment of versions across the Trails stack is done by importing `io.github.yaforster:trails-bom`.
